# 🍳 SoYummy — Кулінарна Платформа

**SoYummy** — це повнофункціональний вебдодаток для любителів готувати. Платформа дозволяє не лише шукати та зберігати рецепти, а й взаємодіяти з іншими користувачами, створюючи власну кулінарну спільноту.

## 🚀 Технологічний стек

### **Frontend**

- **Ядро:** React 18 (Hooks, Functional Components)
- **Управління станом:** Redux Toolkit (Slices, AsyncThunks, Selectors)
- **Навігація:** React Router DOM (Protected & Public Routes)
- **Стилізація:** CSS Modules, адаптивна верстка (Mobile First)
- **Робота з API:** Axios

### **Backend**

- **Платформа:** Node.js & Express
- **База даних:** Sequelize (PostgreSQL/MySQL) — архітектура з використанням зовнішніх ключів та лічильників
- **Автентифікація:** JSON Web Tokens (JWT), Bcrypt
- **Зберігання медіа:** Cloudinary (аватари та зображення страв)

---

## ✨ Основні можливості

- **🔐 Авторизація:** Надійна система реєстрації та логіну з персистенцією даних (Redux Persist).
- **📖 Пошук та фільтрація:** Зручний пошук рецептів за назвою, категорією або інгредієнтами.
- **⭐ Обране (Favorites):** Система збереження рецептів із миттєвим UI-оновленням.
- **👨‍🍳 Власні рецепти:** Повний CRUD (створення, читання, оновлення, видалення) власних кулінарних карток.
- **👥 Соціальна взаємодія:**
  - Підписки на кухарів (**Follow/Unfollow**).
  - Оптимістичне оновлення лічильників підписників у реальному часі.
  - Перегляд профілів інших користувачів та їхньої активності.
- **🛒 Список покупок:** Додавання інгредієнтів прямо з картки рецепта.

---

## 📱 Дизайн та UX

Проєкт реалізовано з фокусом на мобільних користувачів:

1. **Mobile (375px+):** Використання горизонтальних таб-слайдерів (Scroll Snap), компактні картки користувачів.
2. **Tablet (768px+):** Перехід до багатоколонкових списків, відображення прев'ю рецептів у списках підписок.
3. **Desktop (1440px+):** Повнорозмірна сітка контенту, складні ефекти наведення (Hover) та покращена навігація.

---

## 📂 Структура проєкту

- `src/redux/` — централізоване управління станом (слайси `auth`, `users`, `recipes`).
- `src/components/` — бібліотека UI-компонентів (від кнопок до складних списків `UserList`).
- `src/pages/` — сторінки додатку (Home, Search, Profile, Favorites).
- `backend/` — серверна частина (контролери, маршрути та міграції Sequelize).

## 🛠️ Встановлення та запуск

1. **Клонуйте репозиторій:**
   ```bash
   git clone [https://github.com/vladshein/react_nodejs_team_repo.git](https://github.com/vladshein/react_nodejs_team_repo.git)
   ```
2. **Встановлення залежностей:**
   ```bash
   npm install
   ```
3. **Налаштування середовища: Створіть файл .env у корені проєкту та додайте ваші змінні (ключі бази даних, секрети JWT).**
4. **Запуск проєкту:**
   ```bash # Для розробки (Frontend + Backend)
   npm run dev
   ```
